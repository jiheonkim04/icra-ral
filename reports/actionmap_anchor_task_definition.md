# ActionMap Anchor Task Definition

Topic: ActionMap Mini-Anchor Feasibility Gate.

This is not a new method and not a full official ActionMap reproduction. The purpose is to run a minimal local feasibility gate for an ActionMap-style action heatmap before inventing any extension.

Anchor: ActionMap: Robot Policy Learning via Voxel Action Heatmap, arXiv:2606.06904, https://arxiv.org/abs/2606.06904. The official pre-release repository is https://github.com/showlab/ActionMap.

Core mini-gate question: can a local ActionMap-style heatmap/candidate action head beat simple mean, linear/L1, and cheap MLP action heads on local LIBERO HDF5 action quality before any extension or failure mining is proposed?

STATE 1 evidence label: mini ActionMap-style local HDF5 action-head feasibility. This is not official ActionMap reproduction, not standard LIBERO success, not VLA fine-tuning, and not paper-grade evidence.

Non-goals:

- no new method or extension yet,
- no OpenVLA-OFT,
- no full VLA fine-tuning,
- no official full ActionMap reproduction,
- no full benchmark,
- no GPU job,
- no download unless a later official source/size/license/disk risk assessment is green,
- no paper claim,
- no failure mining unless the mini-gate passes,
- no hiding reproduction failure.
