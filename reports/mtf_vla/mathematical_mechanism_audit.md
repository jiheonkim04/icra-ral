# MTF-VLA Mathematical Mechanism Audit

Date: 2026-07-14 KST

Method: `MTF-VLA`, Milestone-Transition Focused VLA Adaptation.

## Variables

For a demonstration or training frame indexed by `i`:

- `x_i`: RGB observation tensor. Shape depends on the official SmolVLA processor; conceptually `[V, C, H, W]` for `V` camera views.
- `q_i`: robot proprioceptive state. Shape `[8]`.
- `u_i`: instruction or task conditioning tokens. Shape processor-defined.
- `a_i`: expert 7D action for the current step. Shape `[7]`.
- `A_i`: expert action chunk when available. Shape `[T, 7]`.
- `g_i`: gripper component of `a_i`. Shape scalar.
- `b_i`: frozen-base action or action chunk generated by the exact Base policy identity on the same input. Shape `[7]` or `[T, 7]`.
- `phi_i`: normalized trajectory progress or phase bin. Shape scalar.
- `s_i`: MTF milestone-transition score. Shape scalar in `[0, 1]`.
- `m_i`: high-milestone selection mask. Shape scalar in `{0, 1}`.
- `r_i`: retention-frame selection mask. Shape scalar in `{0, 1}`.
- `f_0`: frozen Base policy.
- `f_theta`: adapted policy with lightweight trainable adapter parameters `theta`; base weights remain frozen unless the official local trainer requires a named adapter wrapper.

All action discrepancies are measured in normalized action units used by the local SmolVLA action interface for the selected training path.

## Score Construction

Let `d_i = ||a_i - a_{i-1}||_2 + ||a_{i+1} - a_i||_2` when neighbors exist.

Let `k_i = ||(q_{i+1} - q_i) - (q_i - q_{i-1})||_2` when neighbors exist.

Let `h_i = 1` when the gripper sign or open/close state changes between neighboring frames and `0` otherwise.

Robust normalization for a nonnegative sequence `z` within one task or trajectory split is:

`R(z_i) = clip((z_i - median(z)) / (Q90(z) - median(z) + eps), 0, 1)`.

The raw score is:

`s_raw_i = 0.45 * R(d_i) + 0.25 * h_i + 0.30 * R(k_i)`.

Selection then enforces phase coverage by ranking within task and phase bins. This is not an additional learned score term. It prevents the top set from collapsing to one task phase.

High-milestone frames are the top retained ratio per task/phase bin. Retention frames are low-score frames plus clean-retention frames selected from the same development split.

If image access is feasible in Stage 0, the FrameSkip proxy may add a visual-action coherence score. MTF's required score remains the action/state/gripper milestone score above so the method is not blocked by image-decoding cost.

## Objective

For a scalar or chunk action discrepancy, use Huber loss:

`Huber_delta(e) = 0.5 * e^2` when `|e| <= delta`, and `delta * (|e| - 0.5 * delta)` otherwise.

For vector actions, sum or mean over dimensions and chunk steps.

Milestone imitation loss:

`L_milestone(theta) = E_i [ m_i * w_i * Huber_delta(f_theta(x_i, q_i, u_i) - target_i) ]`

where `target_i = a_i` or `A_i`, and `w_i = 1 + s_i`.

Base-retention loss:

`L_retention(theta) = E_i [ r_i * Huber_delta(f_theta(x_i, q_i, u_i) - stopgrad(b_i)) ]`.

Full objective:

`L(theta) = L_milestone(theta) + lambda_ret * L_retention(theta)`.

Default Huber `delta`: `0.05` normalized action units unless Stage 0 magnitude audit shows this is numerically inappropriate. Any change must occur before validation search and be recorded as a development design change, not a confirmatory retune.

## Gradient Path

Gradients flow only into trainable adapter parameters `theta`.

Frozen-base outputs `b_i` are detached and persisted. No gradient flows into `f_0`.

Frame scores `s_i`, masks `m_i`, and retention masks `r_i` are fixed data construction outputs, not learned through confirmatory outcomes.

## Scale And Magnitude Audit

Before full training, Stage 0 or Stage 1 must estimate on a small batch:

- mean `L_milestone`;
- mean `L_retention`;
- gradient norm from `L_milestone`;
- gradient norm from `L_retention`;
- ratio of retention to milestone gradient norm;
- fraction of examples with nonzero `m_i`;
- fraction of examples with nonzero `r_i`.

Hard stop or coefficient adjustment during validation only when one term is numerically overwhelming by more than an order of magnitude and the score/mask health checks still pass. No coefficient adjustment is allowed after confirmatory outcomes.

## Expected Representation Or Action Effect

MTF does not require a new inference-time latent representation. The intended effect is in the adapter's action mapping:

- higher action change on transition-like validation frames;
- lower action change on retention frames;
- preserved gripper behavior unless gripper-transition frames are active;
- valid 7D action bounds;
- no global action replacement.

## Simpler Alternatives

1. `uniform_retained_ratio_lora`: same adapter and training budget, but selected frames are uniform at the retained ratio.
2. `frameskip_proxy_lora`: faithful FrameSkip-style score without MTF's base-retention objective.
3. `mtf_no_retention_ablation`: MTF milestone score but `lambda_ret = 0`.
4. frozen Base.

## Required Ablation

The key ablation is `mtf_no_retention_ablation`.

If it matches or beats full MTF, the identity-preserving retention objective is not useful.

## Known Failure Modes

- Frame scores collapse to a few tasks or phases.
- High-score and low-score sets are not meaningfully different.
- Uniform sampling performs the same or better.
- FrameSkip proxy performs the same or better.
- Retention loss dominates and the adapter becomes Base-equivalent.
- Milestone imitation dominates and clean behavior collapses.
- Frozen-base retention targets are generated from a different policy identity than the Base rollout policy.
- Visual-action coherence is unavailable and the FrameSkip proxy becomes too weak; this must be documented rather than hidden.

## KL And Distribution Policy

MTF uses no KL divergence. The targets are deterministic 7D actions or action chunks, and SmolVLA flow vectors are not assumed to be normalized action probability distributions.

Huber/L2 action discrepancies are mathematically sufficient for this objective.
