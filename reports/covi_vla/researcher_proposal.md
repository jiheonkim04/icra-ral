## Research Claim

Frozen SmolVLA may fail under scene-induced occlusion because task-relevant
object, receptacle, or hand-object evidence is missing or ambiguous in the
current RGB observations. COVI-VLA tests whether a small identity-preserving
visual adapter can infer a complementary-view representation from legal
deployment inputs and improve closed-loop occluded task success while
preserving clean behavior.

COVI-VLA is anchored to LIBERO-Occ / VIM, which reports that scene-induced
occlusion creates substantial VLA performance drops and that viewpoint
imagination can recover useful missing visual evidence. The local method is not
an official VIM reproduction. It is a frozen-SmolVLA-compatible extension that
learns a bounded complementary-view feature update and injects it through a
gate initialized to Base passthrough.

COVI-VLA tests whether complementary-view representation, not ordinary
random-cutout augmentation or direct action residual correction, can improve
the occlusion claim axis beyond:

1. frozen SmolVLA under the same occlusion condition;
2. a transparent VIM-style viewpoint-imagination proxy;
3. the key no-imagined-view ablation;
4. a simple random-cutout clean-retention baseline.

## Mechanism

At timestep `t`, let:

- `o_t`: current deployment observation containing the official RGB streams,
  proprioception, and language/task instruction after the predeclared
  occlusion transform for the targeted condition;
- `a_base_t`: frozen SmolVLA action chunk or emitted 7D action from `o_t`;
- `e_t = E_base(o_t)`: frozen or tapped SmolVLA visual-token representation
  available before action generation;
- `m_t`: predicted occlusion context from legal deployment inputs only;
- `u_t`: compact complementary-view feature predicted from `(o_t, a_base_t,
  m_t)`;
- `delta_e_t`: bounded visual-feature residual derived from `u_t`;
- `g_t`: occlusion-conditioned adapter gate initialized to zero or exact Base
  passthrough;
- `e_covi_t = e_t + g_t * delta_e_t`: adapted visual representation;
- `a_covi_t = pi_base(e_covi_t, q_t, l)`: action produced by the frozen policy
  path using the adapted representation.

The initial policy must equal or be numerically indistinguishable from Base:

- adapter residual initialized to zero;
- gate initialized to zero or Base passthrough;
- action delta p95 audited before rollout;
- translation, rotation, and gripper deltas separately bounded;
- action validity preserved.

The intended mechanism is:

scene-induced occlusion
-> missing task-relevant visual evidence
-> spatially wrong or uncertain Base actions
-> lower closed-loop success.

COVI-VLA
-> complementary-view feature prediction under an occlusion-localized gate
-> better visual evidence for the existing action generator
-> bounded action changes in occluded states
-> higher occluded closed-loop success with clean retention.

## Allowed Sources

At inference COVI may use only:

- current official RGB observations available to SmolVLA, including any
  predeclared occlusion transform applied to the evaluation condition;
- current proprioception/state;
- language or task instruction;
- current frozen SmolVLA action chunk or emitted Base action;
- internally predicted occlusion context and complementary-view
  representation computed from those legal values.

At inference COVI may not use:

- clean unoccluded versions of occluded evaluation images;
- future frames or future actions;
- success, reward, or failure labels;
- reset identity, manifest key, or held-out outcome;
- simulator object pose, segmentation masks, object visibility labels, or
  privileged camera calibration not already available to the policy;
- confirmatory-test identities or outcomes for tuning.

## Supervision

Development-only supervision may use discovery and validation identities to
construct controlled occlusion examples and complementary-view feature targets.
Permitted training labels include:

- clean target features from paired official camera streams before synthetic
  occlusion is applied;
- feature-level reconstruction targets from a frozen visual encoder;
- occlusion masks generated by the predeclared synthetic transform for
  development diagnostics only;
- clean-retention targets on unoccluded development observations;
- Base-action preservation targets for identity and action-validity checks.

Privileged labels may supervise training or auditing only when they are absent
from inference. They may not be used as confirmatory-test inputs.

## Stage 0 Development Audit

Stage 0 must run before validation search, final training, manifest freeze, or
rollout.

Required checks:

1. Split and source gate:
   - discovery, validation, and confirmatory identities are persisted and prove
     zero overlap;
   - inference feature list contains only legal deployment values;
   - no clean evaluation image, segmentation, object pose, success label, reset
     identity, or confirmatory outcome is used at inference.

2. Occlusion headroom:
   - frozen SmolVLA has meaningful development/validation degradation under a
     predeclared scene-induced occlusion condition;
   - the VIM proxy or closest-prior diagnostic leaves residual headroom;
   - a diagnostic upper bound using clean complementary-view features shows
     that the intervention target can matter.

3. Label and target health:
   - occlusion contexts are not all zero or all one;
   - target feature variance is noncollapsed;
   - positive and negative visibility or occlusion examples cover multiple
     tasks and phases;
   - duplicate frame and sample keys are zero;
   - target construction does not leak test identities.

4. Complementary-view predictability:
   - COVI features predict the clean/complementary target above trivial
     image-statistic, direct cutout, and random-cutout baselines by the
     preregistered margin;
   - if ordinary cutout or a no-imagined-view baseline matches the full
     representation, the correct stop is `DESIGN_FAILURE`.

5. Identity and disruption:
   - initial action delta p95 is at most `1e-6`;
   - Base action validity equals `1.0`;
   - translation, rotation, and gripper deltas are separately bounded after
     training;
   - adapter activation is localized to occlusion-relevant states rather than
     global.

6. Gradient and implementation smoke:
   - intended adapter and gate parameters receive finite nonzero gradients;
   - loss magnitudes and gradient norms are reported on a small batch;
   - checkpoint save/reload works before any closed-loop rollout.

Allowed Stage 0 decisions:

- `AUDIT_PASS_PROCEED_TO_VALIDATION_SEARCH`
- `DATA_OR_SUPERVISION_FAILURE`
- `CONDITION_TOO_SEVERE_OR_NO_HEADROOM`
- `DESIGN_FAILURE`
- `IMPLEMENTATION_OR_OPTIMIZATION_FAILURE`

Stage 0 stops are pre-rollout development outcomes, not closed-loop scientific
kills.

## Bounded Validation Search

Run only if Stage 0 passes.

Maximum six configurations:

1. `covi_feat_s005`: feature-residual MLP, residual scale `0.05`
2. `covi_feat_s010`: feature-residual MLP, residual scale `0.10`
3. `covi_feat_s020`: feature-residual MLP, residual scale `0.20`
4. `covi_bottleneck_s005`: bottleneck cross-view adapter, residual scale `0.05`
5. `covi_bottleneck_s010`: bottleneck cross-view adapter, residual scale `0.10`
6. `covi_bottleneck_s020`: bottleneck cross-view adapter, residual scale `0.20`

No other architecture, residual scale, coefficient, occlusion severity,
training seed, source variant, or baseline may be added before confirmatory
testing.

Validation score:

`S = 0.25 * occluded_validation_proxy + 0.20 * feature_predictability_margin +
0.20 * clean_retention + 0.15 * bounded_action_validity +
0.10 * localized_occlusion_activation + 0.10 * efficiency`

The validation score may use development/validation closed-loop success if it
is affordable and identities remain separate. Otherwise it must use the closest
feasible preregistered proxy. It may not use confirmatory identities or offline
action L2 alone.

## First Serious Comparison

Exactly five policies:

1. `frozen_smolvla_occluded`
2. `vim_view_imagination_proxy`
3. `covi_full`
4. `covi_no_imagined_view_ablation`
5. `random_cutout_clean_retention_baseline`

The VIM proxy is a faithful transparent local proxy unless official equivalence
with LIBERO-Occ / VIM is independently established.

## GO And Kill Logic

COVI can become a paper candidate only if:

- `covi_full` beats frozen SmolVLA on the occluded claim axis;
- `covi_full` beats the VIM-style proxy or clearly dominates it under a fair
  matched local protocol;
- `covi_full` beats the no-imagined-view ablation;
- the random-cutout clean-retention baseline does not explain the gain;
- clean behavior is retained;
- representation and action diagnostics support the intended mechanism;
- no privileged inference signal is used.

Kill or stop when:

- no occlusion headroom exists;
- Base, VIM proxy, and diagnostic oracle all fail on a too-severe condition;
- ordinary random-cutout/cutmix training matches COVI;
- complementary-view targets collapse or are not predictable from legal inputs;
- the adapter globally changes actions rather than activating locally;
- clean retention fails;
- the method requires clean evaluation images, object pose, segmentation,
  reset identities, success labels, or confirmatory outcomes at inference.

## Non-Claims

- COVI is not official VIM or official LIBERO-Occ reproduction.
- COVI is not PatchGuard-v1 or a generic random-erasing defense.
- COVI is not LoRA novelty.
- COVI is not a generic confidence head, progress head, verifier, or
  correction wrapper.
- COVI is not an action-history residual, future-action latent, waypoint,
  material-point, scheduler, or chunking rescue.
- COVI does not rescue RAR, CALA, G3P, EAC, PESA, MARC, DAGR, MTF, RAC, FANG,
  CAVM, PSE, RCV, or earlier killed formulations.
